Observação

Instalação pública via site depende do fluxo de distribuição da Apple. Até lá, esta área serve como painel de status.

Atualização rápida

O conteúdo da página é controlado por assets/data/releases.json. Assim, fica simples trocar a versão exibida, adicionar a URL do APK e atualizar o texto do iPhone sem mexer no layout.

Próximos passos sugeridos

Quando o APK de release estiver pronto, basta publicar o arquivo e colar o link no JSON. Para iPhone, a recomendação é migrar para TestFlight ou outro fluxo oficial assim que a conta developer estiver ativa.
